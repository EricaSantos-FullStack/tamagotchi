# Tamagotchi Chewie (flerken procrastinador)

Um pet digital para devs, estudantes e usuários do GitHub que simula um flerken procrastinador!

## Como funciona

- Alimente o Chewie com commits e tarefas realizadas.
- Dê "comida ruim" (tarefas procrastinadas) e veja reações divertidas.
- Chewie pode simular ações absurdas quando está bravo: apagar commit, escrever groselha no README ou criar bugs (simulação visual).
- Notificações "Breaking News" aparecem no canto da página.

## Tecnologias

- React + Vite + TypeScript
- Visual divertido e moderno

## Scripts

- `npm run dev` — inicia o servidor de desenvolvimento
- `npm run build` — build de produção
- `npm run preview` — preview do build
